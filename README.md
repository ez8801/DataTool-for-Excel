# Data tool for Excel
This package is a data tool for Excel.

## Installation

### Install via git URL

To install this package, you need to edit your Unity project's `Packages/manifest.json` and add this repository as a dependency. 
``` json
{
  "dependencies": {
    "com.ez.datatool": "https://github.com/ez8801/DataTool-for-Excel.git",
  }
}
```
